# Data Warehousing and Data Mining Lab Work

Google Colab notebooks from my Data Warehousing and Data Mining course.

| Notebook | Lab |
|---|---|
| `subarnadahal.ipynb` | Loads two IMDb tables (`title.basics` and `title.ratings`), merges them on `tconst` and explores genres, years and ratings |
| `subarna_lab2.ipynb` | Data pre-processing: finding missing values, filling them and encoding categorical columns |

The notebooks read files from my Google Drive (`/content/drive/MyDrive/Colab Notebooks/`). To run them,
download the IMDb files from [datasets.imdbws.com](https://datasets.imdbws.com/) and change the paths.
